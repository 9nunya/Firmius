Implemented the hunk.

The retry model is now `resume focused stopped agent`, not request replay. `Ctrl+R` only works when the focused agent is in `Error` or `Cancelled`; it resumes that same agent from current history without appending a new `user-task-*` turn. Reloaded threads also work because resumed agents now infer persisted stopped state from history, and cancelled runs persist a `cancelled-*` turn so `Cancelled` survives reload. The old harness replay helpers were removed; the legacy `lastRetryableRequest` metadata shape remains only as compatibility baggage, not as the active retry path.

Raw provider error bodies are now surfaced in failed-request messages for the shared OpenAI-style path and Qwen, with HTTP status plus provider/model context included when available. I also added/updated tests for cancelled retry, errored retry, reload retry, unavailable retry, Qwen raw-body formatting, and shared provider raw-body formatting.
